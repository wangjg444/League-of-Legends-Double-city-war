## 作品简介

皮尔特沃夫的光，祖安的雾，一对姐妹被时代推到两端的命运。

本站把《双城之战》两季的核心元素浓缩进一页：世界观介绍、可交互的「全家福」角色海报、以及一个让你在剧集「杀青」之后仍能与角色对话的群聊弹窗。整站采用深色玻璃拟态风格——半透明面板、缓缓流动的渐变光斑、上浮的六边形粒子，营造双城之间那种氤氲流动的氛围。

## 功能亮点

### 🏛 头部 · background introduce（背景介绍）
- 背景故事分为 **4 个小段**：双城格局 / 海克斯与奥术 / 姐妹羁绊 / 两季之战；
- 鼠标悬停介绍文字，会弹出该段对应的**标志性官方剧照**（玻璃相框式、带倾斜角与光晕）；
- 悬停时标题文字有**渐变流光 + 字距展开**动效，正文同步提亮泛光。

### ✨ banner · role（全家福互动）
- 以官方竖版「全家福」海报为舞台，背景为海报的模糊放大版；
- 共 **7 位角色**可交互：蔚、金克丝、凯特琳、杰斯、维克托、希尔科、梅尔；
- 悬停人物时，从角色眼部**一点亮起**光斑，流光沿轮廓**环绕描边**，发光颜色贴合角色性格（蔚·玫红、金克丝·电光蓝、希尔科·微光橙、维克托·奥术青……）；
- 发光 **0.5 秒后**弹出角色个性卡片：一句身份概述 + 一句最出名的台词；
- 点击卡片右上角 **✕**，卡片以缓慢收缩动画退场（也支持 Esc / 点击空白处关闭）。

### 💬 chat · 杀青群聊（弹窗）
- 剧集「杀青」了，戏里的恩怨留在戏里——和 **6 位角色**继续聊天：蔚 / 金克丝 / 凯特琳 / 杰斯 / 维克托 / 希尔科；
- 每位角色有专属开场白、**8 组按性格编写的关键词回复**与兜底台词，聊得越对口越出彩；
- 内置 4 个快捷话题（杀青感受 / 想对搭档说的话 / 最难忘的一幕 / 向观众打招呼），一键发送；
- 头像直接从全家福海报裁切，说话时有打字指示动画。

### 📜 FOOTER
- 明确的**版权归属声明**（Riot Games / Netflix / Fortiche Production 所有，本站为非商业粉丝学习作品）；
- 「感谢体验 · 后会有期」渐变告别语 + 七彩角色光点彩蛋。

### 🌊 整体体验
- 深色玻璃拟态：半透明面板 + `backdrop-filter` 磨砂；
- 缓缓流动：4 团渐变光斑漂移、六边形粒子上浮、标题渐变流光；
- 响应式适配手机端；尊重系统「减少动态效果」偏好（`prefers-reduced-motion`）。

## 快速开始

**方式一：直接打开（推荐）**

双击 `index.html`，用 Chrome / Edge 等现代浏览器打开即可。Vue 运行时与全部图片均已本地化，**离线可用**。

**方式二：本地服务器（可选）**

```bash
# 在项目文件夹内任选其一：
npx serve .
python -m http.server 8080
```

然后访问 `http://localhost:3000`（或 8080，视工具而定）。

**方式三：手机体验**

手机浏览器访问方式二部署的地址即可，布局已适配小屏。

> 浏览器要求：Chrome / Edge 111+ 或同等内核（页面使用了 `color-mix`、`@property` 等较新 CSS 特性）。

## 玩法指南

| 你想做什么 | 怎么做 |
| --- | --- |
| 看背景介绍 | 打开页面即见；鼠标悬停到每段文字上，会弹出对应剧照 |
| 体验角色发光 | 在顶部导航点 **role**，把鼠标放到海报里任意角色身上 |
| 看角色卡片 | 悬停角色发光后稍等 0.5 秒，卡片自动弹出；点 ✕ 收起 |
| 与角色聊天 | 点右上角 **chat**，在左侧选人，输入或点快捷话题发送 |
| 回到顶部 | 点页脚「回到开头 ↑」或导航里的 background introduce |

小技巧：聊天时试试直接聊「姐姐」「搭档」「进化」「微光」「祖安」这些关键词，每位角色的反应都不一样。

## 自定义修改指南

所有可改的内容都集中在两个文件里，改完刷新页面即生效：

**改角色台词 / 聊天回复** → `assets/js/app.js`
- `CHAT_CHARS` 里每个角色的 `open`（开场白）、`kw`（关键词 → 回复池）、`fb`（兜底回复）；
- `CHARS` 里每个角色的 `quote`（卡片台词）与 `desc`（卡片简介）。

**新增海报热区角色** → `assets/js/app.js` 的 `CHARS`
- 添加一项：`clip`（角色的多边形轮廓，百分制 `polygon(...)`）、`sx/sy`（发光起点与卡片锚点）、`color`（性格发光色）、文案；页面会自动生成热区、图例与页脚彩点。

**换图** → 直接替换 `assets/img/` 下同名文件即可（全家福若更换，需要按新海报重新微调 `CHARS` 里的 `clip` 坐标）。

**调视觉** → `assets/css/style.css` 顶部的 `:root` 变量集中管理主色与玻璃参数。

## 常见问题

**Q：双击打开后页面空白？**
A：请确认浏览器为 Chrome/Edge 111+，且 `assets` 文件夹与 `index.html` 保持相对位置完整（整个 `arcane-fan-site` 文件夹一起拷贝）。

**Q：需要联网吗？**
A：不需要。Vue 框架与全部图片均已本地化，离线可完整运行。

**Q：聊天是真的 AI 吗？**
A：不是，是按角色性格人工编写的关键词回复引擎（纯前端、零依赖、零成本）。想要更聪明的回复，可以自行在 `kw` 里扩充词库。

**Q：悬停角色没有发光？**
A：请把鼠标移到角色身上（而不是海报空白处）；触屏设备轻点角色即可触发。

**Q：为什么卡片会出现在角色旁边而不是正上方？**
A：这是有意设计——卡片避开发光点，让发光的人物始终可见。
